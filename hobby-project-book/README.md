# プロジェクト帳

DIY・ガーデニング・料理など、ジャンルを問わず「週末1〜4回で終わる小さなプロジェクト」を
**計画 → 作業 → 完成** まで記録して、次々に回していくためのスマホ向けアプリ（PWA）です。

- アカウント登録・サーバー不要。データと写真はスマホのブラウザ内（IndexedDB）に保存
- ホーム画面に追加すると、アプリのように全画面で使える。オフラインでも動く
- アプリを更新してもデータは消えない
- データ（写真込み）をファイルに書き出し・読み込みできる

## 機能

| 機能 | 内容 |
| --- | --- |
| プロジェクト作成 | まずジャンルを選び、「新しいプロジェクトを作る」か「提案依頼」を選ぶ。タイトルと週末の回数（1〜4回）を決めて作成 |
| 提案依頼 | 選んだジャンルの内蔵アイデア（各30件・計180件）から5つ提案。週末の回数・予算・場所・難しさで絞り込める。分類がばらけるように選び、「別の提案」で順番に違うものが出る。提案から始めると材料・道具・予算・週末ごとの作業が計画に入る |
| 計画 | 材料（数量・金額・用意済みチェック）、道具、予算と残額、週末ごとの作業、メモ。自動保存 |
| 作業記録 | 週末ごとに写真（複数）とメモを追加。写真は長辺1600pxに縮小して保存 |
| 完成ギャラリー | 完成品を写真で一覧。ビフォーアフターをスライド／横並びで比較 |
| お題ストック | やりたいことをメモ。完成時に「次は何をつくる？」でストックから選べる |
| 設定 | バックアップの書き出し・読み込み（追加 or 置き換え）、保存容量の表示 |

## ファイル構成

ビルド不要の素の HTML / CSS / JavaScript（ES Modules）です。

```
index.html             画面の枠（上部バー・下部タブ）
manifest.webmanifest   PWA の設定（アプリ名・アイコン）
sw.js                  Service Worker（オフライン対応。データには触らない）
css/style.css          見た目（先頭の :root で色を変えられる）
icons/                 アイコン
js/
  app.js               画面の切り替え（ルーティング表）
  db.js                IndexedDB（保存の仕組みとデータ移行）
  data.js              データ操作（プロジェクト・記録・写真・お題）
  ui.js                共通部品（モーダル・トースト・写真表示）
  photos.js            写真の縮小
  backup.js            バックアップの書き出し・読み込み
  suggest.js           提案依頼のしくみ（条件・選び方）
  suggestions-data.js  提案に使うアイデア集
  views/               各画面
    home.js            ホーム（進行中の一覧）
    new-project.js     新規作成の入口（ジャンル選択 → 作る／提案依頼）
    project-form.js    プロジェクトの作成・編集
    suggest-view.js    提案依頼の画面
    project.js         計画タブ・作業記録タブ
    complete.js        完成の流れ（ビフォーアフター選択・次のお題）
    gallery.js         完成ギャラリー一覧
    gallery-detail.js  作品の詳細・ビフォーアフター比較
    ideas.js           お題ストック
    settings.js        設定・バックアップ
```

## 機能を追加するには

- **新しい画面**：`js/views/` にファイルを作り、`render(root, params, query, ctx)` を持つオブジェクトを
  `export default` する。`js/app.js` の `ROUTES` に1行足し、`sw.js` の `APP_SHELL` にも追加する。
- **保存する項目を増やす**：プロジェクトなどのオブジェクトに項目を足すだけでよい（古いデータには項目が無いので、
  読むときは `p.newField ?? 初期値` のようにする）。
- **ストア（表）を増やす・構造を変える**：`js/db.js` の `DB_VERSION` を上げ、`MIGRATIONS` に関数を足す。
  既存データは消えずに順番に移行される。バックアップにも含めるなら `js/backup.js` の `DATA_STORES` に追加。
- **ジャンルを増やす**：`js/data.js` の `GENRES` に追加し、`js/suggestions-data.js` にそのジャンルのアイデアを足す。
- **提案のアイデアを増やす**：`js/suggestions-data.js` の該当ジャンルに1行足すだけ（書式はファイル先頭に説明あり）。
- **提案の条件を増やす**：`js/suggest.js` の `CONDITIONS` に1つ足す（画面は自動で増える）。

> 提案依頼は通信を使わない内蔵データ方式なので、料金はかからずオフラインでも動きます。

## データが消えない仕組み

- データは IndexedDB に保存。Service Worker が更新するのはアプリ本体（HTML/CSS/JS）のキャッシュだけ。
- 起動時に `navigator.storage.persist()` で、ブラウザによる自動削除からの保護をお願いしている。
- 念のため、設定画面からときどきバックアップを書き出しておくのがおすすめ。

> 注意：データは「そのブラウザ・そのURL」ごとに保存されます。Safari とホーム画面のアプリは別扱いになることがあるので、
> ホーム画面に追加したらそちらから使ってください。

## ローカルで動かす

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
